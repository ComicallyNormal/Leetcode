


# Background

This is a project that solves Leetcode style problems from a coderpad test I took. Tests validate the functions that are written in the LeetcodeFunctions file
To validate this project, run the LeetcodeFunctionsTests class. This has been validated using java 21 and intellij community edition.

# Usage

After opening the project and building with the intellij gradle tool, navigate to the LeetcodeFunctionsTest file, and run the class level tests by clicking the run button at the top of the class.
